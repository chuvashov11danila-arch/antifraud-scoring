# antifraud-scoring
Антифрод-скоринг клиента
Мини-проект на Python, имитирующий логику принятия решения о выдаче займа (APPROVED / MANUAL / REJECT) на основе нескольких проверок.

## 🕹️ Как это работает
Программа принимает данные клиента и проводит 4 проверки:
1. **Паспорт:** серия (4 цифры) и номер (6 цифр).
2. **Возраст:** отсев (< 18 или > 76), ручная проверка (18-22, 61-76).
3. **Просрочка:** если есть, автоматический отказ.
4. **ПДН (показатель долговой нагрузки):** расчет и вывод в отчете.

В конце выводится подробный отчет: какое решение принято и какие проверки пройдены.
